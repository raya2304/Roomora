# Roomora — Room Design Planner

Roomora is an interactive room design planner that helps users customize room colors, arrange furniture, explore interior design themes, and estimate furniture costs through a clean and responsive interface.

## Features

- **Interactive Room Planner:** Customize your room layout and position furniture.
- **Furniture Library:** Add and remove furniture items such as sofas, beds, desks, plants, and tables.
- **Color Customization:** Change wall and floor colors using preset palettes or custom colors.
- **Interior Design Themes:** Explore Modern Beige, Forest Green, Coastal Blue, and Warm Earth themes.
- **Room Size Adjustment:** Adjust the room dimensions using an interactive slider.
- **Budget Estimation:** Calculate estimated furniture costs based on selected items.
- **Save and Load Designs:** Store your design in the browser using LocalStorage.
- **Export Design Summary:** Download a text file containing room details, furniture, colors, and estimated costs.
- **Responsive Design:** Use the website on desktop and mobile devices.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- CSS3
- LocalStorage API

## Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/roomora-room-design-planner.git
   ```

2. Navigate to the project folder:

   ```bash
   cd roomora-room-design-planner
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

4. Start customizing your room design.

Tailwind CSS is loaded through its CDN, so an internet connection is required for the styling framework to load.

## How to Use

1. Select a room type from the room planner.
2. Choose furniture from the furniture library.
3. Drag furniture to arrange your room.
4. Customize wall and floor colors.
5. Apply an interior design theme.
6. Adjust the room dimensions and review the estimated budget.
7. Save your design or export the room summary.

## Limitations

Roomora is currently a front-end project. Designs are stored locally in the browser, the 3D preview is a visual perspective effect, and furniture costs are illustrative estimates rather than live market prices.

This project demonstrates front-end development skills, responsive UI design, DOM manipulation, event handling, interactive customization, and browser-based data persistence.
